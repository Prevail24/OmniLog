# OmniLog
*Captures every keystroke.*

## The Basics

### The Setup
1. Install **Python 3.x**.
2. Install the listener: `pip install pynput`
3. Ignite the program: `python logger.py`

### The Evidence
All data is exhaled into a single file: `keylog_data.txt`.

* `Key pressed: h` $\rightarrow$ *A character was born.*
* `Special key pressed: Key.enter` $\rightarrow$ *A thought was completed.*

## 🗝️ 

* **For The Analyst:** Capture raw, unfiltered human input data.

## ⚙️ Technical Soul

- **Engine:** Python 3 / `pynput`
- **Reach:** Windows, macOS, Linux.
- **The Escape:** Press `Esc` to stop the recording and freeze time.
